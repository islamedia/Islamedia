ISLAMEDIA.FR — MODE D'EMPLOI DU SITE
=====================================

Ce dossier contient tout le site. Il fonctionne tel quel : pas de base de
données, pas de logiciel à installer.


1. CE QU'IL Y A DANS LE DOSSIER
-------------------------------
  index.html ............ la page d'accueil (le contenu : textes, sections)
  coran/ ................ le Coran : le sommaire (coran/index.html), une
                          page par sourate (coran/1/ à coran/114/) et la
                          lecture page par page (coran/page/)
  mushaf.js ............. la lecture page par page (rien à modifier)
  horaires/ ............. les horaires de prière (page et liste des villes)
  tr/ ................... la version turque du site : accueil (tr/index.html),
                          Kur’an (tr/kuran/), namaz vakitleri
                          (tr/namaz-vakitleri/), yasal bilgiler
  horaires.js ........... le calcul des horaires (rien à modifier)
  style.css ............. l'apparence (couleurs, polices, animations)
  script.js ............. les animations et le bloc RÉGLAGES (tes liens)
  mentions-legales.html . la page obligatoire en France
  404.html .............. la page affichée si une adresse n'existe pas
  polices/ .............. Manrope, Inter et Scheherazade New (hébergées sur le site).
                          Pour l'arabe : Scheherazade New 4.400 de SIL, réglée pour
                          écrire la kasra sous la lettre quand il y a une chadda
                          (ٱلدِّينِ).
  images/ ............... motif, favicon, icône iPhone, aperçu de partage
  CNAME ................. indique à GitHub Pages ton adresse : islamedia.fr
  robots.txt, sitemap.xml  pour Google
  .nojekyll ............. fichier technique pour GitHub Pages (il peut être caché)


2. METTRE LE SITE EN LIGNE GRATUITEMENT (GitHub Pages + ton domaine IONOS)
--------------------------------------------------------------------------
Le domaine acheté chez IONOS, c'est l'adresse. Il faut aussi un hébergement,
l'endroit où vivent les fichiers. GitHub Pages l'offre gratuitement.
À faire sur ton ordinateur.

 A. Compte GitHub
    Va sur github.com et crée un compte gratuit. Ton nom d'utilisateur
    (TONPSEUDO) apparaîtra dans l'adresse provisoire du site. GitHub peut te
    demander d'activer la double authentification : accepte.

 B. Créer le dépôt
    En haut à droite : « + » puis « New repository ».
    Repository name : islamedia — laisse « Public » — « Create repository ».

 C. Envoyer les fichiers
    Décompresse le ZIP (clic droit > Extraire tout), puis ouvre le dossier
    islamedia-site. Sur la page du dépôt, clique sur « uploading an existing
    file ». Sélectionne TOUT le contenu du dossier (Ctrl + A) et glisse-le dans
    la page : les fichiers et les dossiers polices et images.
    ⚠ Glisse le contenu, pas le dossier islamedia-site lui-même.
    En bas : « Commit changes ».

 D. Activer GitHub Pages
    Onglet « Settings » > « Pages » (menu de gauche).
    « Build and deployment » > Source : « Deploy from a branch ».
    Branch : « main » et « / (root) » > « Save ».
    Le champ « Custom domain » doit afficher islamedia.fr (grâce au fichier
    CNAME). Sinon, tape islamedia.fr et clique « Save ».

 E. Brancher le domaine chez IONOS
    Espace client IONOS > « Domaines & SSL » > menu « ⋯ » à côté
    d'islamedia.fr > « DNS ».
    1) Supprime les enregistrements A et AAAA existants dont le nom d'hôte est
       @ (ils pointent vers la page d'attente d'IONOS), et celui de www.
       Ne touche pas aux enregistrements MX, TXT ou SPF (ce sont les e-mails).
    2) « Ajouter un enregistrement » > type A > nom d'hôte @ > pointe vers :
         185.199.108.153
       Si IONOS propose d'ajouter aussi l'enregistrement pour www, décoche.
       Recommence trois fois avec :
         185.199.109.153
         185.199.110.153
         185.199.111.153
    3) « Ajouter un enregistrement » > type CNAME > nom d'hôte www >
       pointe vers : TONPSEUDO.github.io   (ton nom d'utilisateur GitHub)
    Facultatif (IPv6) : 4 enregistrements AAAA pour @ vers
       2606:50c0:8000::153   2606:50c0:8001::153
       2606:50c0:8002::153   2606:50c0:8003::153

 F. Activer le HTTPS
    Attends de 15 minutes à quelques heures. Dans GitHub > Settings > Pages,
    coche « Enforce HTTPS » dès que la case devient cliquable (jusqu'à 24 h).
    Ton site est en ligne : https://islamedia.fr

 G. Conseillé pour la sécurité
    GitHub > ta photo > Settings > Pages > « Add a domain » : vérifie
    islamedia.fr en ajoutant chez IONOS l'enregistrement TXT qu'il te donne.
    Personne d'autre ne pourra alors utiliser ton domaine sur GitHub.


3. AUTRE SOLUTION : HÉBERGEMENT IONOS (payant)
----------------------------------------------
Tarifs vus sur ionos.fr le 16/11/2026 : pack Standard à 3 € HT/mois pendant
6 mois, puis 6 € HT/mois. Si tu prends un pack d'hébergement :
  1) Dans l'espace client, ouvre l'espace web (Webspace) de ton pack.
  2) Envoie tout le contenu du dossier islamedia-site à la racine.
  3) Dans « Domaines & SSL », relie islamedia.fr à cet espace web, puis
     active le certificat SSL.
  4) Dans mentions-legales.html, remplace le bloc « Hébergement » par
     l'adresse d'IONOS (elle est déjà écrite en commentaire dans le fichier).
Les fichiers CNAME et .nojekyll ne servent pas chez IONOS : tu peux les
laisser, ils ne gênent pas.


4. MODIFIER LE SITE
-------------------
 • Tes liens (TikTok, Instagram, YouTube), ton e-mail et ton nom :
   ouvre script.js, remplis le bloc RÉGLAGES tout en haut, enregistre.
   Les boutons apparaissent tout seuls quand un lien est rempli : dans la
   partie Contact de l'accueil, sur les séries vidéo et en bas de chaque page.
   TikTok et Instagram sont déjà remplis (@islamedia.fr sur les deux).
   Il reste YouTube, ton e-mail et ton nom.
   Sur GitHub : clique sur script.js > icône crayon > modifie >
   « Commit changes ». Le site se met à jour en une minute environ.
 • Les textes : dans index.html, les phrases sont lisibles entre les balises.
   Cherche le texte à changer avec Ctrl + F.
 • Mentions légales : ton nom et ton e-mail se remplissent depuis RÉGLAGES.
   En France, le site doit indiquer qui l'édite, un contact et l'hébergeur.


5. FIABILITÉ DES VERSETS
------------------------
 • Texte arabe : Tanzil Project, texte uthmani 1.1 (lecture Hafs), recopié
   automatiquement, sans saisie à la main. Les 6 236 versets ont été comparés
   automatiquement, lettre par lettre puis signe par signe, au texte du
   Complexe du Roi Fahd publié par QuranEnc : les lettres sont identiques
   partout ; 2 petits signes de lecture diffèrent (2:72 et 17:7). Les signes
   de pause (waqf) ne sont pas affichés dans cette version.
   Licence Tanzil : texte non modifié, source citée, lien vers tanzil.net.
 • Traduction du sens : Muhammad Hamidullah, fichier fr.hamidullah de
   Tanzil.net (mise à jour du 18 juillet 2011), reproduit sans modification.
   Les 6 236 versets ont été contrôlés un par un contre une seconde copie du
   même fichier. Tanzil réserve ses traductions à un usage non commercial :
   c'est le cas du site (ni publicité, ni vente). Si un jour le site devient
   commercial, il faudra l'accord de l'éditeur de la traduction, ou passer à
   la version de QuranEnc, qui autorise la republication.
 • Traduction turque (version turque du site) : traduction de la Diyanet
   İşleri Başkanlığı, fichier tr.diyanet de Tanzil.net (mise à jour du
   27 décembre 2011), reproduit sans modification. Contrôles : le fichier a
   exactement la même empreinte (SHA-256) que celui téléchargé sur tanzil.net
   le 3 novembre 2026 par un autre projet, et ses mots sont identiques, verset
   par verset, à ceux d'une autre copie publiée (quran-json). Mêmes
   conditions que Hamidullah : usage non commercial.
   La Diyanet traduit parfois plusieurs versets d'un bloc (570 fois, par
   exemple Nâs 1 à 6) : ces versets sont affichés ensemble, l'arabe de chaque
   verset puis la traduction une seule fois.
 • Recherche : dans le sommaire du Coran, taper « 3:13 » (ou « 3/13 »,
   « Baqara 255 ») mène directement à la sourate 3, verset 13.
 • Lecture page par page (coran/page/, en turc tr/kuran/sayfa/) : les 604
   pages du Mushaf de Médine, avec les mêmes versets sur chaque page. Le
   découpage a été comparé verset par verset dans deux sources publiées
   (quran-api et quran-meta) : elles concordent pour les 6 236 versets. Les
   lignes suivent la largeur de l'écran, elles ne reproduisent pas celles du
   Mushaf imprimé. Une adresse comme islamedia.fr/coran/page/#440 ouvre
   directement la page 440 ; le site reprend à la dernière page lue.
 • Pour ajouter un verset, ne le tape jamais à la main : demande-le à partir
   de ces sources.


6. HORAIRES DE PRIÈRE
---------------------
 • La page horaires/ calcule les horaires dans le navigateur du visiteur :
   rien n'est envoyé, et elle marche pour n'importe quelle date.
 • Méthode par défaut : Diyanet (DITIB), calendrier européen de la Diyanet
   (imsak 18°, yatsı 16°, temkin, règle d'été au nord de 44,5°). Le calcul a
   été comparé à 2 394 horaires officiels de la Diyanet pour 2026, dans 13
   villes : 95 % identiques à la minute, aucun écart de plus d'une minute.
 • Autres méthodes au choix : Musulmans de France (12°), Ligue islamique
   mondiale, 15° (ISNA), Égypte, Umm al-Qura, Karachi ; asr standard ou
   hanafite. Le visiteur choisit sa ville (toutes les communes de France
   et des DOM de plus de 1 000 habitants, plus les grandes villes de
   Belgique, de Suisse et du Luxembourg, et Monaco) ou se localise ; son
   choix reste dans son navigateur.
 • Sans choix, la ville affichée est Paris, y compris sur l'accueil.
 • Liste des villes : GeoNames (licence CC BY 4.0, citée sur la page).
   Genève et Anvers y figurent depuis le 18/11/2026 (elles manquaient).


7. VERSION TURQUE (tr/)
-----------------------
 • Chaque page existe en français et en turc. Le bouton « TR » (ou « FR »),
   en haut de chaque page, ouvre la même page dans l'autre langue, au même
   verset sur les pages du Coran.
 • Les pages turques sont fabriquées à partir des pages françaises : si tu
   modifies un texte français de l'accueil ou des mentions légales, demande
   aussi sa traduction, sinon la fabrication du site s'arrête (c'est voulu :
   la page turque ne peut pas rester en retard).
 • Les vidéos n'existent qu'en français : la version turque n'a donc pas
   la rubrique « Nos séries » (ni dans le menu, ni sur l'accueil).
 • Le menu est le même sur toutes les pages (y compris les mentions
   légales) : il est fabriqué à un seul endroit (outils/coran.py).
 • Les mentions légales turques sont une traduction pour information : c'est
   la version française qui fait foi.
 • Fais relire les textes turcs par une personne dont c'est la langue
   maternelle (menus, explications, horaires).


8. METTRE À JOUR LE SITE AVEC UN NOUVEAU ZIP
--------------------------------------------
 • Sur GitHub, ouvre ton dépôt > « Add file » > « Upload files ».
 • Glisse tout le contenu du nouveau dossier islamedia-site : les fichiers
   qui portent le même nom sont remplacés, les autres restent. « Commit
   changes ». Le site se met à jour en une à deux minutes.
 • GitHub accepte au plus 100 fichiers par envoi. Le site complet en compte
   plus, il est donc livré en 2 parties :
     - partie 1 : glisse tout le contenu du dossier islamedia-site, puis
       « Commit changes » ;
     - partie 2 : ouvre son dossier islamedia-site et glisse uniquement le
       dossier coran, puis « Commit changes ». Il complète le dossier coran
       envoyé avec la partie 1.
 • Le fond animé de l'accueil s'appelle « Mosquée de nuit ». Deux autres fonds
   existent (« Zellige doré » et « Moucharabieh ») : demande-les si tu
   préfères en changer.
